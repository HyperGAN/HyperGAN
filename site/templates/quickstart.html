Go from a clean virtual environment to a validated hypergan-model/1 configuration, live training telemetry in the Web Observatory, and a standalone exported generator in under a minute.

Runtime & Python Support

Lightweight package commands (new, validate, ps, status, logs, inspect, runs, queue, gc, rm) support Python 3.11–3.14 on Linux, macOS, and Windows without importing PyTorch. For training, CI tests Python 3.12+ with torch==2.14.0 and torchvision==0.29.0.

Which run rm, gc, stop and tag act on

Mutating commands resolve targets strictly to prevent accidental deletion: pass an exact run ID (or 8-character short ID), slug, tag set via hypergan tag, run directory name, or path to a run directory (containing manifest.json or summary.json). Prefix/substring matching, workspace roots, registered runs roots, $HOME, /, and symlinks are refused. With no target, commands act on the current directory if it is a run; stop also stops a sole active run.

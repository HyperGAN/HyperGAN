# DINOv3 HNDL discriminator at 128px

The new recipe uses the existing SAGAN/AdaIN generator and replaces the ResNet
feature branch with frozen DINOv3 ViT-S/16. The pixel branch is byte-identical
through `pixel_score`; raw zero-image context is preserved in both paths.
One native pretrained readout returns normalized transformer depths 2, 5, 8, 11,
each 384×8×8, from a shared candidate/context batch. Four HNDL heads project
768 context-joined channels to 64 and read out scalar scores. Final weighting is
`(pixel + sum(four feature scores) / 2) / sqrt(2)`.

All discriminator topology and preprocessing are in
`examples/networks/dinov3-multidepth-discriminator-128.hndl`.
The trusted provider registers the upstream constructor and existing named
readout; its source checkout options are now available to generic `factory="hndl"`
components. Shape checks derive the input patch grid and retain 256px support.
No HNDL release beyond 0.4.0 is needed.

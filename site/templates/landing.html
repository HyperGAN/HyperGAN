Architecture

Built for reproducible generative research and deployment.

01 / DECLARATIVE

hypergan-model/1 + HNDL

Declare data, priors, multi-port HNDL networks (or custom PyTorch nn.Modules), losses, and evaluations in versioned TOML with static shape verification before allocating a GPU.

Inspect {{ meta.counts.schema_fields }} schema fields →
02 / OPTIMIZATION

ParticleGAN unified_v11

Learned latent particle tables with coupled_max multi-critic thermal coordination and dual-safe fwAD softmax penalties for mode coverage and stable convergence.

Read integration boundary →
03 / OBSERVABILITY

Web Observatory + Foldlite DB WASM

Append-only Foldlite DB journals drive a local browser observatory with a shared Rust/WASM streaming reducer, live loss/FID curves, EMA preview sliders, and inline HNDL layer tables.

Web Observatory guide →
04 / SCALING

Multi-GPU NCCL Scaling

Launch single-host replicated training with --devices 0,1, bounded preview budgets, resumable checkpoints, and explicit execution profiles for CPU, CUDA, and Docker.

View scaling measurements →
05 / DEPLOYMENT

Standalone Generator Export

Bake EMA generator weights with SHA-256 provenance into Python bundles (bundle), PyTorch pt2, onnx, or safetensors — with sample() and spherical interpolate().

Deployment guide →
06 / OPERATIONS

Docker-Style Run Registry & Queue

Daemonless global registry tracks every run by short ID, memorable slug (fleet-hawk), or custom tag. Control runs from any directory with ps, status, logs, stop, gc, and a multi-GPU job queue.
